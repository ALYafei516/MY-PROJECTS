A project consisting of a comprehensive recruitment website that aims to simplify the process of job searching and applying within the company. The system allows applicants to browse available jobs and search for them easily, then fill out the application form and enter the required information in an organized and professional manner.

On the other hand, the system provides the HR team with a dedicated interface to review submitted applications, where they can view the list of applicants, select the most suitable candidates for the jobs, and communicate with them directly.

The platform was built using Angular for the user interface and .NET Web API for the backend, ensuring high performance and a smooth user experience, with a flexible design and scalability to meet future business needs.
